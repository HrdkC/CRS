# Configuration glossary

| Term | Meaning |
|---|---|
| Machine/Stage | Independent configuration owner, for example P01 First Stage |
| PLC Assignment | The active PLC registry record used by one machine/stage |
| Tag Purpose | Stable CRS meaning mapped to a physical PLC tag |
| RECIPE_DATA | CRS source recipe buffer restored from the database |
| TEST_RECIPE_DATA | Configured destination/running buffer used by the download workflow |
| Parameter Template | Human name, PLC array index, unit, minimum, maximum, default, and Used state |
| Used Parameter | Parameter included in recipe creation and validation |
| Phase Control | Stage-specific allowed sequence selection, separate from numeric parameters |
| Readiness | Live validation of required configuration, not a manual checkbox |
| Engineering Tools | Advanced repair and raw rule controls hidden from the standard journey |
