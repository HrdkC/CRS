PROJECT DECISIONS LOG
=====================

Decision 001
------------

Machine Ownership

Decision:

Machine belongs to one TBM Family.

Reason:

Physical machine identity is unique.

Examples:

P03 Family_A

Valid

P03 Family_B

Invalid

--------------------------------------------------

Decision 002
------------

Machine Code Standardization

Decision:

Machine codes are case-insensitive.

Examples:

P03 = p03

Reason:

Avoid duplicate machine records.

--------------------------------------------------

Decision 003
------------

Stage Creation

Decision:

Stages created automatically.

FIRST_STAGE

SECOND_STAGE

Reason:

All PCR TBMs have both stages.

Manual stage creation unnecessary.

--------------------------------------------------

Decision 004
------------

Template Ownership

Decision:

Templates belong to:

Machine + Stage

Reason:

PLC mappings differ by machine and stage.

--------------------------------------------------

Decision 005
------------

Recipe Structure

Decision:

Recipes store values.

Templates define structure.

Reason:

Allows template expansion without redesign.

--------------------------------------------------

Decision 006
------------

Recipe Validation

Decision:

Entire stage recipe must pass validation.

No partial download allowed.

Reason:

Prevent incomplete recipe downloads.

--------------------------------------------------

Decision 007
------------

Phase Controls

Decision:

Dropdown selection only.

No free text entry.

Reason:

Reduce operator mistakes.

--------------------------------------------------

Decision 008
------------

Time Handling

Decision:

Store UTC

Display IST

Reason:

Consistent database handling.

--------------------------------------------------

Decision 009
------------

Database Strategy

Decision:

SQLite for development.

MySQL for production.

Future MSSQL support.

Reason:

Flexibility and portability.

--------------------------------------------------

Decision 010
------------

Workstation Recovery

Tables

User Experience
