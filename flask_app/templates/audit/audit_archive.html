Operation Guide

Short explanation for safe plant operation.

Download active audit Creates Excel and downloads through the browser. Best for manual Save As.
Save to approved server path CRS saves Excel only to whitelisted plant locations.
Archive old records Moves old rows from active audit to archive table using Retention Days.
Excel backup during archive Recommended. Creates Excel backup of the same rows before archiving.
