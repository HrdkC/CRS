Operation Guide

Use the right action for the maintenance job.

Download active audit Creates Excel and downloads through browser. User chooses save path in browser.
Save to approved server path CRS writes Excel to a configured plant/server folder from the dropdown.
Archive old audit records Moves old rows from active audit table to archive table. Active audit stays fast.
Export Excel during archive Yes creates an Excel backup of archived rows. No only moves rows to archive.
