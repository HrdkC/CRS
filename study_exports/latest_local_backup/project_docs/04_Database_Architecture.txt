DATABASE ARCHITECTURE
=====================

Database Philosophy
-------------------

Development:
- SQLite

Production:
- MySQL

Future:
- MSSQL

Application code should remain database-independent.

All database access should occur through central managers and helpers.

Migration Philosophy
--------------------

Application startup should:

- Create missing tables
- Create missing columns
- Create default settings
- Create default data

Minimal manual setup should be required.

Time Philosophy
---------------

Store all timestamps in UTC.

Display all timestamps in IST.
