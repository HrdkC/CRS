CRS V11.6 - Semantic Disable / Enable / Active Standardization
Date: 2026-07-17

Purpose
-------
Standardize semantic action and status colors across the complete CRS UI:

- Disable / destructive action: RED background + WHITE text.
- Disabled / blocked / failed status: RED background + WHITE text.
- Enable / positive action: GREEN background + WHITE text.
- Active / OK / Ready / Released status: GREEN background + WHITE text.
- Primary / Edit / Open action: BLUE background + WHITE text.
- Truly unavailable or locked controls: NEUTRAL SLATE background + readable LIGHT text.

Important distinction
---------------------
A button labelled "Disable" is a destructive action and is red.
A control that is disabled/unavailable because it cannot be clicked is neutral slate,
not red. This avoids presenting a locked control as a destructive action while also
preventing white-on-white text.

Implementation notes
--------------------
1. The final module is imported last to override earlier page/theme rules.
2. Route-aware selectors cover /disable/ and /enable/ forms even if a future template
   omits a semantic class.
3. Template status classes now explicitly include status-active or status-disabled.
4. Existing PLC, recipe, user, family, machine, engineering-unit and parameter actions
   retain their routes and behavior; only semantic UI classes and styles were changed.
5. The production CSS bundle is rebuilt and cache-busted to V1.20.
