Most Important Decisions
------------------------

Machine Codes

- Globally unique
- Case insensitive

Examples:

P03 = p03

Only one machine record may exist.

Family changes require editing the machine.

Do not create duplicate machine records.

--------------------------------------------------

Stages

Automatically created.

FIRST_STAGE

SECOND_STAGE

No manual stage creation required.

--------------------------------------------------

Templates

Templates belong to:

Machine + Stage

Not Family.

Not Global.

--------------------------------------------------

Recipes

Recipes store values.

Templates define structure.

--------------------------------------------------

Current Released Recipe Editing

Current RELEASED recipe values are editable with audit for operator ease of use.

Historical released versions remain locked and read-only.

Create Version is used for major revisions, trial work, or controlled recipe development, but it is not mandatory for every small current-production correction.

Required controls:

- Min/max validation
- Old value / new value audit
- Changed by
- Changed at
- Reason / remarks
- Machine
- Stage
- Source

--------------------------------------------------

Validation

No partial recipe download allowed.

Entire stage recipe must pass validation before download.

--------------------------------------------------

Phase Controls

FIRST_STAGE

- One recipe-controlled phase block.
- 12 selectable recipe rows.
- Each row selects from the machine/stage eligible phase master.
- PLC string case is machine/stage-specific and must be preserved exactly.

SECOND_STAGE

- Cap Strip Side is recipe-controlled.
- B&T Side is recipe-controlled.
- Shaping Side is PLC-fixed standard sequence and must not be written as recipe phase-control rows.
- Do not include Shaping Side in recipe editor selections, template import/export, restore payload, save-from-PLC, comparison, download validation, or recipe audit changes.

Dropdown selection only.
